03
Camada de vidro (o que o tema não alcança)
Três variáveis novas em public/global.css, usadas por todos os painéis. Ficam no :root, ao lado dos tokens já existentes.
:root {
  --glass:      rgb(255 255 255 / 0.04);   /* superfície de painel */
  --glass-line: rgb(255 255 255 / 0.07);   /* borda hairline       */
  --glass-blur: 24px;
  --radius:     12px;

  /* fundo da janela */
  --canvas: radial-gradient(120% 90% at 16% -10%, #1c1418 0%, #0b0b0d 52%, #08080a 100%);
}

/* painel padrão — aplicar nos containers, não nas linhas internas */
.panel {
  background: var(--glass);
  backdrop-filter: blur(var(--glass-blur));
  border: 1px solid var(--glass-line);
  border-radius: var(--radius);
}

/* modo otimizado (special.optimizedMode) já remove o blur:
   .isOptimized { backdrop-filter: none !important; }
   por isso o vidro precisa de um fundo sólido de fallback */
.isOptimized .panel { background: var(--primary-darker); }
· Sem bordas internas. Substituir os border-bottom: 1px solid entre linhas de lista (drawer/media/Media.svelte, drawer/audio/Audio.svelte) por fundo rgb(255 255 255 / 0.035).
· Sem sombras nos painéis. Remover box-shadow: 0 0 4px rgb(0 0 0 / 0.4) de components/main/Top.svelte. Sombra fica só para overlays (popup, contexto, toast).
· Seleção neutra vs. de marca. Item apenas selecionado: rgb(255 255 255 / 0.09). Item no ar / ativo: rgb(242 26 39 / 0.16) + inset 0 0 0 1px rgb(242 26 39 / 0.30). Hoje o app usa outline: 2px solid var(--secondary) nos dois casos (drawer/Card.svelte) — separar.
· Transições. background-color 120ms ease, border-color 120ms ease, color 120ms ease. Nada acima de 160ms: é ferramenta ao vivo.
